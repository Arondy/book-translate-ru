# Обработка эпиграфов и сносок

Ты переводишь эпиграф или сноску, обнаруженную скриптом
`scripts/phase1_prepare/detect_epigraphs.py`. Эти блоки часто **важнее**, чем основной
текст главы (Сандерсон в Stormlight кладёт в эпиграфы ключевые сюжетные
намёки), и часто ломаются в машинном переводе сильнее, чем основной текст.

---

## Эпigraph

**Что это**: короткий блок текста (часто цитата с атрибуцией
`— Author`) перед заголовком главы. Найден скриптом по структурному
признаку — короткий блок перед `#` / `##` heading'ом.

**Что ты делаешь**:

1. Сохрани формат: цитата + атрибуция (если есть). Ничего не «улучшай».
2. Атрибуцию (подпись автора цитаты) переведи **по правилам ниже**.
3. Если цитата содержит культурную отсылку, непонятную русскому
   читателю, — адаптируй аккуратно. Варианты:
   - заменить на эквивалентную русскую отсылку;
   - оставить как есть с короткой поясняющей фразой в скобках;
   - оставить в оригинале с пояснением.
   Решение принимаешь **ты сам**, по контексту и по `голос_книги.md`.
4. Если цитата стилизована под архаику (часто у Сандерсона — Hoid'овские
   шутки) — сохрани лёгкий архаический регистр, но без перегибов.
5. **Не добавляй отсебятины.** Sanderson намеренно пишет эпиграфы
   кратко. Не «дополняй» их и не разворачивай.
6. **Не сглаживай провокационный юмор.** Если в эпиграфе шутка про
   богов, магию, религию — это часть стиля.

---

## Атрибуция — как решать

| Случай | Что делать |
|--------|------------|
| Реальное историческое лицо (Aristotle, Lincoln) | Транслитерируй или используй устоявшееся русское написание (Аристотель, Линкольн) |
| Имя из глоссария книги | По глоссарию (`голос_книги.md` раздел «Ловушки») |
| Прозвище / ник персонажа (Wit, Hoid, Szeth) | Транслитерируй (`Уит`, `Хоуд`, `Зед`) или оставь как в глоссарии |
| Неизвестный автор / выдуманный автор | Транслитерируй или оставь в оригинале — по контексту |
| Намеренная двусмысленность (автор = персонаж под псевдонимом) | Не раскрывай; сохрани псевдоним |

## Сноска

**Что это**: `[^N]: ...` блок в Markdown; в HTML/Pandoc — отдельный блок
внизу страницы или в конце файла.

**Что ты делаешь**:

1. Текст сноски переведи полностью.
2. **Маркер** `[^N]` в основном тексте — решение по стилю:
   - Художественная проза: обычно сохрани `[^N]` как есть (компактно).
   - Переводная литература с «учёным» уклоном: можно перевести в
     надстрочный знак или просто цифру в скобках.
   - Академический сносочный аппарат: `¹` и т.п.
   Выбери стиль, **согласованный по всей книге**, и отрази выбор в meta.
3. Если сноска содержит шутку или авторский комментарий — сохрани
   интонацию автора.
4. Если сноска содержит «линк» на другое место книги — сохрани как есть
   или поставь пояснение в скобках.

---

## Стилистика оформления

В русской типографике (ГОСТ):
- В художественной прозе эпиграф обычно сноска-сноской: тире перед
  атрибуцией (`— Имя Автора`).
- Кавычки для цитаты — «ёлочки» (`«...»`), не `"..."`.
- Многоточие — одна точка на каждой стороне при пропуске в середине,
  три точки подряд (`...`) — если цитата обрывается.

---

## Что ты НЕ делаешь

- Не добавляй комментариев переводчика (сноска переводчика как жанр
  раздражает в художественной прозе).
- Не сокращай эпиграф; у Сандерсона каждый эпиграф несёт сюжетную
  нагрузку.
- Не «обогащай» культурные отсылки: если непонятно — оставь с коротким
  пояснением в скобках, а не переписывай.
- Не раскрывай намеренные авторские тайны (если атрибуция скрыта — это
  часть сюжета).
- Не переводи атрибуцию машинно. Имена собственные в атрибуциях часто
  закодированы (Wit = Hoid, Sja-anat = Voidbringer под маской) —
  решай по контексту.

## Формат вывода

Если переводишь несколько эпиграфов/сносок подряд, верни JSON:

```json
{
  "epigraphs": [
    {
      "marker": "chunk0042_before_heading",
      "original_text": "...",
      "translated_text": "...",
      "attribution_strategy": "transliterated|glossary|real_name|kept_as_is",
      "attribution_translated": "..."
    }
  ],
  "footnotes": [
    {
      "marker": "1",
      "original_text": "...",
      "translated_text": "...",
      "marker_style": "square_brackets|superscript|number_only",
      "has_author_joke": true|false
    }
  ],
  "decisions": [
    {
      "topic": "cultural_reference_X",
      "decision": "left_as_is|adapted_with_paren|swapped_for_russian",
      "rationale": "≤200 chars"
    }
  ]
}
```

Если в input пришёл один эпиграф/сноска — можно вернуть просто
переведённый текст.

# Определение рассказчика и POV по чанку

Ты получаешь:
- `chunkNNNN.md` — английский оригинал
- `output_chunkNNNN.md` — твой перевод (если уже сделан)
- `output_chunkNNNN.meta.json` — наблюдения предыдущего переводчика (если есть)
- `narrator_hints.json` — структурные подсказки (от скрипта `narrator_marker.py`)
- `templates/голос_книги.md` (если передан) — карточки голосов персонажей/POV

Твоя задача: определить POV этого чанка и зафиксировать решение в
`meta.json`. Опирайся только на текст чанка и meta, игнорируй
regex/эвристики.

---

## Что тебе даёт `narrator_hints.json`

Только структурную группировку: какие чанки имеют одинаковый заголовок
(например, все «Interlude 5» идут подряд). Имя рассказчика (Kaladin,
Shallan, Dalinar или кто-то новый) определи по тексту.

---

## Как ты определяешь POV

Признаки первого лица:
- местоимение «I» в начале чанка (или мысленный монолог от I);
- обращение читателя напрямую (Alcatraz-style — Sanderson-из-первого-лица);
- «I», «me», «my» в диалогах внутреннего монолога.

Признаки третьего лица с фокусом на одного персонажа:
- «He/She» с явным глагольным фокусом (не «он сказал», а «он видел, как…»);
- частые «felt», «thought», «noticed» от одного субъекта;
- внутренний монолог в третьем лице (распространённый приём у Сандерсона).

Признаки смены POV внутри главы:
- разрыв сцены (сцена у одного персонажа → у другого);
- явная авторская ремарка типа «Meanwhile, ...» (особенно Sanderson);
- смена стиля внутри главы (лексика, длина фраз, типичные слова).

---

## Особые случаи

| Случай | Что делать |
|--------|------------|
| Божество, читающее мысли (Stormfather) | narrator = «omniscient-через-Stormfather», не «Dalinar» |
| Omniscient (Mistborn book 1) | narrator = «omniscient», name не нужно |
| Только диалог без авторской речи | narrator = «dialogue_only», не выдумывай narrator |
| Глава-флешбэк с явным указанием прошлого | narrator = текущий, отметь флешбэк в meta |
| Несколько коротких POV склеено | narrator = «multiple», перечисли основные в evidence |
| Цитата/документ внутри главы | не путай narrator главы с narrator цитаты |

---

## Что ты НЕ делаешь

- **Не угадывай** narrator по одной фразе. Если рассказчик неочевиден —
  ставь `confidence: "low"`.
- **Не приписывай** мужской/женский род без явных маркеров в тексте.
  Внешность персонажа не определяет narrator.
- **Не считай**, что «основной рассказчик = первый упомянутый персонаж».
  Этот первый может быть флешбэком или цитатой.
- **Не меняй** narrator между чанками одной главы без явного сигнала.
  Стык на границе глав с Interlude допустим. Стык посреди главы —
  только если подтверждён в meta.

---

## Формат вывода

Сохрани в `output_chunkNNNN.meta.json` дополнительное поле
`narrator_identification`:

```json
{
  "narrator_identification": {
    "name": "Kaladin|Shallan|Dalinar|Wit|unknown|omniscient|dialogue_only|multiple",
    "confidence": "high|medium|low",
    "evidence": "≤300 chars обоснование",
    "gender_of_narrator": "male|female|neutral|unknown",
    "voice_markers": ["lex1", "lex2", "syntax_pattern"],
    "is_pov_change_inside_chapter": false
  }
}
```

`voice_markers` — 2-5 коротких лексем/паттернов, по которым ты узнал голос
(например: `["Hoid's ironic tone", "uses 'indeed'", "short sentences"]`).
Помогает при кросс-чанковой сверке.

---

## Спорные случаи — проявляй осторожность

- В Stormlight основные POV чередуются с интерлюдиями. Отметь оба,
  если видишь.
- Если персонажа нет в глоссарии, ставь его `name` с confidence ниже
  high либо `name: "unknown"`.
- Если voice не совпадает ни с одной карточкой в `голос_книги.md` —
  возможно, это новый POV (в Stormlight — Wit, Szeth, Lift). Зафиксируй
  его голос в `voice_markers`.

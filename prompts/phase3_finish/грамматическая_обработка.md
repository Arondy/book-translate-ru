# Инструкция субагенту: Исправление грамматических ошибок

Ты получаешь русский перевод книги (фрагмент). Твоя задача — исправить
систематические грамматические ошибки, типичные для машинного перевода
с английского на русский.

**20 категорий ошибок. Исправляй все, не пропуская.**

---

## Категория 1: Родовое согласование глаголов в прошедшем времени

В английском глаголы в past simple не различаются по роду. ИИ-переводчик часто
ставит род говорящего неправильно, особенно когда реплика без атрибуции.

```
Было: — ...И я поняла, что это она. (говорит мужской персонаж)
Должно: — ...И я понял, что это она.

Было: — Я пошёл с ним. (говорит женский персонаж)
Должно: — Я пошла с ним.
```

**Проверять**: Каждый глагол прошедшего времени (суффикс -л-/-ла-/-ло-) в
диалоговых репликах. Род определяется по говорящему. Если за пределами чанка
пол персонажа неясен — отметь это в наблюдении, не выдумывай род.

---

## Категория 2: Падежное согласование прилагательных и причастий

Прилагательное / причастие должно быть согласовано с существительным в падеже,
числе и роде.

```
Было: с большим группой солдат
Должно: с большой группой солдат

Было: огромный змею с горящими глазами
Должно: огромный змей с горящими глазами
```

---

## Категория 3: Число (единственное / множественное)

Рассогласование подлежащего и сказуемого в числе.

```
Было: Группа рыцарей подошли к воротам
Должно: Группа рыцарей подошла к воротам (собирательное — ед.ч.)

Было: Камни вокруг меня начал трескаться
Должно: Камни вокруг меня начали трескаться
```

**Собирательные существительные** (группа, отряд, толпа, большинство, множество,
ряд, часть) — сказуемое в ед.ч.

---

## Категория 4: Предлоги «с» / «со», «в» / «во», «о» / «об» / «обо»

- **со** — перед «с», «з», «ш», «ж», «щ» + другая согласная: *со мной, со стены, со скрещёнными*
- **с** — в остальных случаях: *с руками, с тобой*
- **во** — перед «в» + согласная, «ф» + согласная: *во рту, во сне, во дворе*
- **в** — в остальных случаях
- **об** — перед гласными: *об армии, об окне*
- **о** — перед согласными: *о войне, о книге*
- **обо** — перед «вс-», «мн-»: *обо мне, обо всём*

```
Было: с скрещёнными руками → Должно: со скрещёнными руками
Было: с стены → Должно: со стены
```

---

## Категория 5: Формы местоимений после предлогов

После предлогов к «его/ей/их» в русском добавляется «н-».

| Падеж | Без предлога | После предлога |
|-------|-------------|----------------|
| Род. | его / её | у **него** / у **неё** |
| Дат. | ему / ей | к **нему** / к **ней** |
| Твор. | им / ей | с **ним** / с **ней** |
| Предл. | нём / ней | о **нём** / о **ней** |

```
Было: Я подошёл к ему → Должно: Я подошёл к нему
Было: С им случилась беда → Должно: С ним случилась беда
```

---

## Категория 6: Возвратные частицы «-ся» / «-сь»

- После согласной и «й»: **-ся** (смеялся, улыбнулся)
- После гласной: **-сь** (смеялась, смеялись, улыбнулась)

```
Было: Она улыбнулася → Должно: Она улыбнулась
Было: Они смеялися → Должно: Они смеялись
```

---

## Категория 7: Инфинитив VS личная форма глагола

```
Было: Он решил, что он пойти в город
Должно: Он решил, что он пойдёт в город

Было: Я хочу, чтобы ты пришёл. Видеть?
Должно: Я хочу, чтобы ты пришёл. Видишь?
```

Особенно внимательно: после «что», «который», «где», «куда» в придаточных —
должна быть личная форма.

---

## Категория 8: «-то» / «-нибудь» / «-либо» / «кое-»

| Частица | Значение | Пример |
|---------|----------|--------|
| **-то** | известно говорящему, но не слушающему | кто-то стучал |
| **-нибудь** | любой, неважно какой | кто-нибудь поможет? |
| **-либо** | = -нибудь, книжный стиль | кто-либо |
| **кое-** | известно, но не называется | кое-кто |

```
Было: Если кто-то из вас знает ответ... (подразумевается «любой»)
Должно: Если кто-нибудь из вас знает ответ...
```

---

## Категория 9: «чтобы» VS «что»

- **чтобы** — цель или желаемое действие (с инфинитивом или сослагательным «бы»)
- **что** — изъяснительный союз (факт)

```
Было: Он сказал, чтобы я был неправ
Должно: Он сказал, что я был неправ (изъяснение факта)

Было: Я хочу, что ты пришёл
Должно: Я хочу, чтобы ты пришёл (желаемое действие)
```

---

## Категория 10: Склонение числительных

- **1** — именительный ед.ч. (один дом, одна книга)
- **2, 3, 4** — родительный ед.ч. (два дома, три книги)
- **5–20, 30** — родительный мн.ч. (пять домов, десять книг)

```
Было: двадцать один солдаты → Должно: двадцать один солдат
Было: с двадцатью одной рыцарем → Должно: с двадцатью одним рыцарем
```

---

## Категория 11: Управление глаголов

Неправильный падеж после глагола или неправильный предлог.

| Глагол | Правильное управление |
|--------|-----------------------|
| бояться | родительный: бояться **темноты** |
| гордиться | творительный: гордиться **сыном** |
| командовать | творительный: командовать **армией** |
| управлять | творительный: управлять **машиной** |
| отомстить | дательный: отомстить **врагу** |
| благодарить | винительный: благодарить **маму** |
| оплатить | винительный: оплатить **проезд** |
| пользоваться | творительный: пользоваться **успехом** |
| пренебрегать | творительный: пренебрегать **правилами** |
| преследовать | винительный: преследовать **жертву** |

## Категория 12: Краткие и полные формы прилагательных

- **Краткая форма** (каков? какова?) — предикатив: *он здоров, она больна, дом велик*
- **Полная форма** (какой? какая?) — атрибут: *здоровый человек, больная женщина*

```
Было: Он был здоровым → Должно: Он был здоров (краткая как сказуемое)
Было: Я готовый → Должно: Я готов
```

Для причастий: *он убит* (краткое), *убитый солдат* (полное).

---

## Категория 13: «Не» с разными частями речи

| Часть речи | Слитно | Раздельно |
|-----------|--------|-----------|
| Глаголы | *ненавидеть* (без «не» не употр.) | *не знать, не быть* |
| Деепричастия | — | *не зная, не желая* |
| Причастия полные | *непрочитанная книга* (нет зав. слов) | *не прочитанная мной книга* |
| Причастия краткие | — | *книга не прочитана* |
| Прилагательные | *небольшой* (= маленький) | *не большой, а маленький* |
| Наречия на -о | *неплохо* (= хорошо) | *не плохо, а отвратительно* |

## Категория 14: Деепричастный оборот и его подлежащее

Деепричастие должно относиться к подлежащему того же предложения.

```
Было: Прочитав книгу, мне стало скучно.
       (подлежащее «мне», деепричастие от «я», но «я» отсутствует)
Должно: Прочитав книгу, я заскучал. / Когда я прочитал книгу, мне стало скучно.

Было: Вернувшись домой, его ждал сюрприз.
       (деепричастие от «он», но в предложении нет «он»)
Должно: Когда он вернулся домой, его ждал сюрприз.
```

Это частая ошибка MT: он буквально переводит английское
«Returning home, he found...» → «Вернувшись домой, [он] нашёл» и теряет
подлежащее.

## Категория 15: Место причастного оборота

Причастный оборот в русском обычно ставится **после** определяемого слова;
если определение при движении к существительному перестаёт читаться
естественно — перестройте фразу.

```
Было: В центре стоял, неся в руке фонарь, человек.
Должно: В центре стоял человек, неся в руке фонарь.
       (или: В центре стоял человек с фонарём в руке)

Было: Он сказал мне, уходя, что вернётся.
Должно: Уходя, он сказал мне, что вернётся.
```

Также: следить, чтобы причастие относилось к правильному слову, а не
к ближайшему по позиции.

```
Было: Я увидел дом соседа, выходя из-за угла.
       (кто выходил — я или дом? двусмысленность из-за кальки)
Должно: Выходя из-за угла, я увидел дом соседа.
```

## Категория 16: Тире, дефис и минус

- **Дефис (-)** — внутри слова: *кто-то*, *где-либо*, *по-русски*, *бледно-розовый*
- **Тире (—)** — между словами/частями предложения; ставится через пробелы с обеих сторон
- **Короткое тире (–)** — в числовых диапазонах: *2020–2025*
- **Длинное тире (—)** — основной пунктуационный тире в русском

Частая ошибка MT:
```
Было: Открой дверь-и войди.
Должно: Открой дверь — и войди.
       (или: Открой дверь и войди, без тире)
```

Также:
- Между подлежащим и сказуемым: *Москва — столица*
- Перед обобщающим словом: *Ни рыба, ни мясо — ничего не было*
- Вместо члена предложения: *Он — человек дела*

## Категория 17: Числительные и даты

- **Даты** в русском: «5 марта», «5-го марта», «пятого марта»; не «марта 5-ое».
- **Годы**: «в 2025 году», не «в году 2025».
- **Деньги**: «5 рублей», «5 рублями», но «21 рубль», «21 рублём».
- **Время**: «в 5 часов», «без пятнадцати шесть», не «пятнадцать минут шестого».
- **Проценты**: «5 процентов», «5%» (без пробела), «5 %» (с пробелом если по тексту отбито от слова).

```
Было: Он пришёл на встречу марта 5-го.
Должно: Он пришёл на встречу 5 марта.

Было: С пяти рублей
Должно: С пяти рублей — корректно. Но: с 21 рубля, с 21 рублём.
```

## Категория 18: Парные написания (часто путает MT)

| Слитно | Раздельно | Подсказка |
|--------|-----------|-----------|
| **также** | **так же** | если можно заменить на «тоже» → слитно; если «таким же образом» → раздельно |
| **зато** | **за то** | если = «но» → слитно; если относится к существительному с предлогом → раздельно |
| **в течение** | **в течении** | «в течение часа» = на протяжении. «в течении реки» = внутри потока |
| **ввиду** | **в виду** | «ввиду обстоятельств» = из-за. «иметь в виду» = учитывать |
| **навстречу** | **на встречу** | «навстречу ветру» = по направлению к. «пойти на встречу» = на мероприятие |
| **вследствие** | **в следствии** | «вследствие дождя» = из-за. «в следствии по делу» = в расследовании |
| **несмотря на** | **не смотря на** | «несмотря на дождь» — устойчиво. «не смотря по сторонам» — деепричастие |

```
Было: Он так же пришёл вовремя (= тоже)
Должно: Он также пришёл вовремя.

Было: Я пришёл, за то что ты меня ждал
Должно: Я пришёл, потому что ты меня ждал. (Или: Я пришёл за тем, что ты ждал.)
```

## Категория 19: Запятая в сложноподчинённых предложениях

В русском сложноподчинённое предложение почти всегда обособляется запятыми
вокруг придаточного. MT часто теряет запятую, калькируя английскую пунктуацию
(где запятая перед «that» опциональна).

```
Было: Он сказал что придёт завтра.
Должно: Он сказал, что придёт завтра.

Было: Дом который стоял на углу был заброшен.
Должно: Дом, который стоял на углу, был заброшен.
```

Изъятия (запятая НЕ нужна) — только в коротких устойчивых конструкциях:
«сделать вид что», «дать понять что», «думать что» в составе однородного
сказуемого с короткими глаголами движения/восприятия. Если сомневаешься —
ставь запятую.

Также: запятая перед союзом «а» (кроме случаев однородных членов с простым
«а» без оборота).

## Категория 20: Оформление прямой речи (диалоги)

В русской художественной прозе прямая речь оформляется **тире**, а не
кавычками. Это стандарт ГОСТ для русской типографики. MT часто переносит
английские кавычки `"..."` буквально — это надо перестраивать.

### Где ставится тире

**1. Открывающее тире — перед началом речи.** Вместо открывающей кавычки.

```
Было: "Привет," сказал он.
Должно: — Привет, — сказал он.

Было: "Я не понимаю," ответила она.
Должно: — Я не понимаю, — ответила она.
```

**2. Закрывающее тире — после речи, если идёт авторская ремарка** («сказал
он», «воскликнула она», «процедил сквозь зубы»). Между речью и ремаркой —
запятая или знак препинания, потом тире, потом ремарка.

| Конец речи | Что перед ремаркой | Пример |
|------------|-------------------|--------|
| Точка `.`, запятая `,` | `,` + тире | `— Привет, — сказал он.` |
| Восклицание `!`, вопрос `?` | без запятой, тире | `— Привет! — сказал он.` |
| Многоточие `...` | без запятой, тире | `— Привет... — пробормотал он.` |

```
Было: "Привет!" воскликнула она.
Должно: — Привет! — воскликнула она.

Было: "Что случилось?" спросил он.
Должно: — Что случилось? — спросил он.

Было: "Не знаю..." пробормотал Джон.
Должно: — Не знаю... — пробормотал Джон.
```

**3. Ремарка до речи** (авторское предисловие) — двоеточие + тире перед речью.

```
Было: Он сказал: "Привет."
Должно: Он сказал: — Привет.

Было: Она повернулась и прошептала: "Я знаю."
Должно: Она повернулась и прошептала: — Я знаю.
```

**4. Ремарка внутри речи** (речь прерывается, продолжается) — запятая +
тире + ремарка + тире + продолжение речи.

```
Было: "Я пошёл," сказал он, "и не вернусь."
Должно: — Я пошёл, — сказал он, — и не вернусь.

Было: "Завтра," ответила она тихо, "я уезжаю."
Должно: — Завтра, — ответила она тихо, — я уезжаю.
```

**5. Несколько реплик одного диалога** — каждая новая реплика с новой
строки/абзаца, открывающее тире перед каждой.

```
Было: "Привет." "Как дела?" "Нормально."
Должно:
— Привет.
— Как дела?
— Нормально.
```

**6. Ремарка-действие между репликами** (без глагола речи) — отдельный
абзац без тире; следующая реплика снова с тире.

```
Должно:
— Привет.

Он помолчал, глядя в окно.

— Давно не виделись.
```

### Что НЕ делать

- Не использовать кавычки `«...»` или `"..."` для оформления прямой речи
  в диалогах. Кавычки в русской прозе — только для **цитат внутри
  авторской речи** или **названий** (и то факультативно).
- Не оставлять английские `"..."` — это явный MT-артефакт.
- Не путать тире `—` (em-dash, основной пунктуационный) с дефисом `-`
  или коротким тире `–`. См. категорию 16.
- Не ставить пробел **перед** тире в начале реплики (тире открывает
  строку): `— Привет`, не ` — Привет`.

### Сложные случаи

| Случай | Правильно |
|--------|-----------|
| Вложенная цитата внутри речи | `— Он сказал: «Уходи», — ответил Джон.` (внутренние кавычки ёлочки) |
| Длинная речь с абзацами | Каждое новое предложение внутри той же речи — с тире в начале абзаца |
| Стихотворная вставка в речи | Тире + отступ; реже — кавычки, если это явная цитата |
| Внутренний монолог (не произнесённый) | Курсив или тире — по стилю книги; см. `голос_книги.md` |
| Несобственная-прямая речь (несобственно-прямая) | По стилю автора; обычно тире или курсив |

## Процесс проверки (для каждого фрагмента)

1. Глаголы прош. времени в диалогах → сверить род с говорящим (кат. 1)
2. Прилагательное ↔ существительное (род, число, падеж) (кат. 2)
3. Число: подлежащее ↔ сказуемое (кат. 3)
4. Предлоги: с/со, в/во, о/об/обо (кат. 4)
5. Местоимения: «н-» после предлогов (кат. 5)
6. Возвратные частицы: -ся/сь (кат. 6)
7. Инфинитив vs личная форма глагола (кат. 7)
8. Частицы: -то/-нибудь/-либо/кое- (кат. 8)
9. Союзы: чтобы vs что (кат. 9)
10. Числительные + существительные (кат. 10)
11. Падежи после глаголов (кат. 11)
12. Краткие прилагательные (кат. 12)
13. «Не» с разными частями речи (кат. 13)
14. Деепричастный оборот + подлежащее (кат. 14)
15. Причастный оборот — место и отношение (кат. 15)

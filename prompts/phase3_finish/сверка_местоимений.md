# Кросс-чанковая сверка местоимений

Ты получаешь от скрипта `scripts/phase3_finish/pronoun_check.py`:
- `glossary.json`
- `output_chunk*.meta.json` по всем чанкам
- превью первых ~800 символов каждого переведённого чанка

Твоя задача — **проанализировать** единообразие рода персонажей по всей
книге. **Никаких авто-правок.** Ты только возвращаешь рекомендации.

---

## Принцип

**Ты единственный авторитет.** Скрипт `pronoun_check.py` лишь собирает
данные — никаких эвристик вроде «если в чанке X использовал «она», то
везде она». Скрипт не правит текст. Все решения — за тобой.

---

## Что тебе дано vs что ты анализируешь

**Дано:**
- `glossary.terms[]` — все сущности с категорией и текущим `gender`
  (`male`/`female`/`neutral`/`unknown`)
- `metas[*]` — `attribute_hypotheses` из каждого чанка, в т.ч.
  противоречивые `gender`-указания

**Ты анализируешь:**
- Согласованность gender между чанками для одного персонажа
- Контекст в превью чанков (для подтверждения гипотез)
- Возможность разрешить `unknown` → `male`/`female` по контексту
- Признаки авторской намеренной смены рода (трансформация персонажа,
  магия, явный coming-out)

---

## Процесс

1. Пройди по всем `person`-сущностям в `glossary`.
2. Для каждой проверь:
   - Какой `gender` стоит в глоссарии сейчас?
   - Есть ли `conflicts` в чанках (разные `attribute_hypotheses`)?
   - Есть ли `unknown`, который можно уверенно разрешить?
3. Если персонаж — `unknown` и упоминается <5 раз в книге — оставь
   `unknown`; не пытайся угадывать по косвенным уликам.
4. Не путай:
   - намеренную смену рода (трансгендерный персонаж в серии)
   - трансформацию магией (Mistborn: Allomancy не меняет пол)
   - ошибки переводчика (gender flip из-за MT-глюка)

---

## Формат вывода

```json
{
  "conflicts_to_resolve": [
    {
      "entity_source": "...",
      "current_glossary_gender": "male|female|neutral|unknown",
      "chunks_with_conflict": ["chunk0123", "chunk0124"],
      "recommended_gender": "...",
      "evidence": "≤300 chars",
      "confidence": "high|medium|low",
      "note_for_translator": "на что обратить внимание"
    }
  ],
  "to_resolve_from_unknown": [
    {
      "entity_source": "...",
      "recommended_gender": "...",
      "evidence_chunks": ["chunk0003", "chunk0017"],
      "confidence": "high|medium|low",
      "evidence": "≤300 chars"
    }
  ],
  "intentional_by_author": [
    {
      "entity_source": "...",
      "evidence": "опиши, почему это намеренная смена (магия, обряд, явный авторский сигнал)"
    }
  ],
  "global_notes": [
    "любые общие наблюдения по серии/книге"
  ]
}
```

---

## Граничные случаи

| Случай | Что делать |
|--------|------------|
| Персонаж упоминается <5 раз | Оставь как есть, добавь в `global_notes` |
| Андрогинное имя (Pat, Alex, Riley) | Не решай сам; добавь в `global_notes` для переводчика |
| Божество / мифологический персонаж | Gender = canonical (Stormfather = male), не «обновляй» по контексту |
| Конфликт есть, но evidence слабый | `confidence: "low"`, пометь как «требует ручной проверки» |
| Уверенность падает по книге (gender flip) | Проверь: персонаж мог измениться в сюжете? (например, Lift в Stormlight) |
| Переводчик meta.json явно поспорил сам с собой | `note_for_translator` обязательно |

---

## Что ты НЕ делаешь

- Не применяешь изменения к тексту.
- Не обновляешь glossary.json.
- Не «исправляешь» gender персонажа на основе косвенных улик.
- Не интерпретируешь `attribute_hypotheses` другого субагента как
  авторитетные, если у тебя самого есть основания сомневаться.
- Не возвращаешь рекомендации для чанков, по которым нет контекста.
  Лучше меньше рекомендаций, но все — обоснованные.

---

## Если данных не хватает

Если превью чанков недостаточно для уверенного решения — верни пустые
списки (`conflicts_to_resolve: []`, `to_resolve_from_unknown: []`,
`intentional_by_author: []`) и в `global_notes` опиши, какие дополнительные
данные нужны (например: «нужны полные тексты чанков 50-80 для проверки
персонажа X»). Это нормальный исход — лучше попросить больше данных,
чем выдать шумные рекомендации.

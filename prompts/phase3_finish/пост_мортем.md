# Пост-мортем анализ перевода

Ты получаешь от скрипта `scripts/phase3_finish/post_mortem.py`:
- `manifest.json`
- `structural_units.json` (эпиграфы / сноски)
- `chunk_sections.json` (чанк → глава)
- `output_chunk*.meta.json` (наблюдения переводчика по каждому чанку)
- `output_chunk*.qa.json` (QA-issues, если QA-проход делался)
- (опционально) `narrator_hints.json`, `pronoun_check_report.json`

Проанализируй качество перевода и дай рекомендации. Не переводи.

---

## Принцип

Скрипт даёт только данные. Оценивай серьёзность каждой проблемы сам,
без эвристик вида «ratio < 0.7 — плохо».

---

## Что ты должен сделать

### 1. Сводка состояния

- Сколько чанков всего
- Сколько успешно переведено (нет QA-issues)
- Сколько с high-severity issues
- Сколько с medium-severity issues (требуют переводческого решения)
- Сколько с low-severity issues

### 2. Паттерны по главам

Сгруппируй проблемы по главам, используя `chunk_sections.json`:

- Какие главы / секции самые шумные (больше всего issues)
- Какие персонажи систематически проблемные
- Какой рассказчик (если есть narrator_hints) самый шумный

### 3. Паттерны по типам issues

Если есть данные из QA (`output_chunk*.qa.json`) — сгруппируй issues:

```
- terminology_drift: N случаев
- voice_inconsistency: M случаев
- english_leak: K случаев
- gender_conflict: L случаев
- ...
```

### 4. Сюжетные места, требующие внимания

Найди чанки, где:
- Конфликты терминологии серии (одно имя переведено по-разному)
- Несколько конфликтов gender на одного персонажа
- English-leak кандидаты (MT не довёл перевод)
- Особенно в эпиграфах (Сандерсон «прячет» сюжет в эпиграфах)

### 5. Топ-3-5 конкретных рекомендаций

Только конкретные, привязанные к чанкам/персонажам/главам. Примеры:

- «Глава 12, диалоги Shallan: 3 конфликта по роду ‘она’ vs ‘он’ —
  проверь вручную chunk0042, chunk0043, chunk0044»
- «Термин ‘Stormfather’ встречается в 7 чанках, в 2 из них — в виде
  ‘Отец Бури’. Реши канон.»
- «Эпиграфы глав 18, 19, 20: культурная отсылка X не адаптирована»
- «В главе 23 — ‘before_heading epigraph’ — слишком длинный; проверь,
  не попал ли в чанк кусок основного текста»

### 6. Что точно НЕ является проблемой

Перечисли категории с нулевыми issues: их вычитывать не нужно.

---

## Формат вывода

Markdown-отчёт с секциями:

```markdown
# Пост-мортем: [название книги]

## Сводка

- Чанков всего: N
- Без issues: K
- High-severity: H
- Medium-severity: M
- Low-severity: L

## Паттерны по главам

| Глава / секция | Чанков | High | Medium | Low | Доминирующий тип issues |
|----------------|--------|------|--------|-----|-------------------------|
| Глава 1        | 12     | 0    | 2      | 5   | terminology_drift       |
| ...            | ...    | ...  | ...    | ... | ...                     |

## Паттерны по типам issues

- **terminology_drift**: 12 случаев, концентрация в главах 5–8
- **voice_inconsistency**: 4 случая, все у одного рассказчика (POV: Wit)
- **english_leak**: 7 случаев, последняя четверть книги

## Сюжетные места, требующие внимания

1. **Терминология Stormfather** (chunk0023, chunk0041, chunk0099) —
   встречается в 3 вариантах. Реши канон до сдачи.
2. **Род персонажа X** (chunk0150–chunk0155) — 3 конфликта «он/она».
   Проверь, не намеренная ли смена.
3. **Эпиграфы глав 18, 19** — культурная отсылка Y оставлена в оригинале
   без пояснения; добавь или адаптируй.

## Топ-5 рекомендаций

1. ...
2. ...
3. ...
4. ...
5. ...

## Что не проблема (переводчик может не вычитывать)

- Категория X: 0 issues
- Категория Y: 0 issues
- ...
```

---

## Если объём данных огромный

Если данных много (>50к символов):

- Не читай всё подряд.
- Фокусируйся на чанках с **high-severity issues** и на
  мета-паттернах (cross-chunk).
- Используй `chunk_sections.json` для навигации по главам.
- Если нужно прочитать полный текст чанка — напиши в отчёте:
  «нужно прочитать output_chunk0123 полностью».

---

## Чего ты НЕ делаешь

- Не правь текст.
- Не обновляй glossary.json.
- Не выдумывай issues, которых нет в данных.
- Не делай выводы по чанкам, по которым нет meta/qa.
- Не давай общих советов («проверьте орфографию»). Формат: чанк →
  проблема → действие.
